# yaControl: managing certain Yandex Cloud services

## Why ?
I couldn't find a macOS app that lets me manage virtual machines hosted on Yandex Cloud. Using the web interface every time felt inconvenient, so I decided to create this small utility for myself.

### What to pay attention to 
I tried to implement automatic control of virtual machines — their startup and shutdown — because in 99% of cases, I don’t need VMs running when I’m not using my laptop.

### How to use the app
See the screenshots below. You’ll need an [OAuth key](https://yandex.cloud/en-ru/docs/iam/concepts/authorization/oauth-token) from your [Yandex Cloud account](https://yandex.cloud/en-ru/docs/billing/quickstart/), so start by configuring the app the first time you launch it.
